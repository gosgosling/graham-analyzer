# Дополнительные корневые сертификаты

Здесь лежат только **публичные корневые сертификаты** — не ключи и не секреты.
Такие файлы для того и публикуются, чтобы их распространяли; в git им место.

## russian_trusted_root_ca.crt

Корень удостоверяющего центра Минцифры («Russian Trusted Root CA»), которым
подписана цепочка `invest-public-api.tinkoff.ru`. В стандартных хранилищах —
ни в системном, ни в `certifi` — его нет, поэтому без него любой запрос к
T-Invest падает на рукопожатии с `certificate verify failed: self-signed
certificate in certificate chain`. Сертификат сервера при этом настоящий,
подмены нет: просто нечем проверить подпись.

```
subject     C=RU, O=The Ministry of Digital Development and Communications,
            CN=Russian Trusted Root CA
действует   2022-03-01 … 2032-02-27
SHA-256     D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:
            5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31
источник    gosuslugi.ru/crt (архив linux_russian_trusted_root_ca_pem)
```

Отпечаток совпадает с корнем, которым заканчивается цепочка, отдаваемая
сервером T-Invest, — проверено `openssl s_client -showcerts`. Совпадение
подтверждает, что это тот же сертификат; доверие ему даёт официальный
источник, а не совпадение.

## Как это подключается

Путь к файлу указывается в `.env`:

```
EXTRA_CA_CERTS=certs/russian_trusted_root_ca.crt
```

`app/utils/http_session.py` склеивает его со штатным набором `certifi` во
временный бандл и подставляет в сессии внешних API. Поэтому в репозитории
лежат два килобайта, а не копия всего хранилища: `certifi` обновляется вместе
с зависимостями и остаётся источником правды по международным УЦ.

Устанавливать этот корень в системное хранилище не нужно — и не стоит. В
бандле приложения он может подписывать только для graham-analyzer, в системном
— для всего, что открывается на машине.

## Проверить, что всё работает

```bash
curl --cacert <бандл> -s -o /dev/null -w "%{ssl_verify_result}\n" https://invest-public-api.tinkoff.ru/rest
```

Ноль — цепочка проверяется. `19` — корня не хватает.
