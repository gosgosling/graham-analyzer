Эталоны выгружены из БД (`verified_by_analyst = true`):

* LKOH 2024, 2023, 2021
* NVTK 2025, 2024, 2023

лежат в `tests/fixtures/golden/`.

Офлайн-тесты проверяют движок сравнения (`compute_report_diff`):

* идеальное совпадение → score 100% на каждом эталоне;
* акции ÷1000 → `mismatch`;
* нет амортизации → `missing_ai`;
* обязательства = капитал+обязательства → `mismatch`;
* округление <1% → `close`/`match`.

Живой прогон LLM по PDF:

```bash
GOLDEN_PDF_DIR=/path/to/pdfs pytest -m live_extraction -v
```

Сейчас **skipped** — каталог PDF не задан. Перед массовым заполнением компаний
положите PDF эталонов (`LKOH_2024.pdf`, `NVTK_2023.pdf`, …) и прогоните один раз:
это и есть метрика «насколько агент читает правильно».

Обновить фикстуры из БД после правок эталонов:

```bash
venv/bin/python scripts/export_golden_reports.py
```

## Рекомендации перед массовым AI-заполнением

1. Прогнать `pytest -m live_extraction` на PDF ЛУКОЙЛа и НОВАТЭКа, зафиксировать score.
2. Порог `EXTRACTION_MIN_SCORE=0.70` — стартовый; если по ключевым полям
   (equity, revenue, net_income, shares, D&A) стабильно ≥80%, можно расширять.
3. Все AI-черновики оставлять с `verified_by_analyst=false` до ручной сверки.
4. После сверки эталонного года — перевыгрузить фикстуры скриптом выше.
