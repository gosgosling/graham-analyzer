# Знак проекта — варианты

Шесть направлений, нарисованных 30.09.2026. Решение не принято. Холст с
крупными знаками, связками со словесной частью и фавиконками:
https://claude.ai/artifact/M9YNf4H8CToRhXaKJBvjhp (приватный, открывается владельцем).

Цвета — из интерфейса (`frontend/src/styles/tokens.css`): цена `#818cf8`,
опорная `#fb923c`, запас `#34d399`, фон знака `#1c222c`. Для светлой темы —
`#4f46e5`, `#ea580c`, `#059669` на `#eef1f6`.

| Файл | Идея |
|---|---|
| `logo-variants/1-zona-zapasa-*` | Цена уходит под ступеньку опорной, между ними — запас. Главный график в одном знаке. |
| `logo-variants/2-monogramma-g-*` | Буква G, перекладина — ступенька опорной. |
| `logo-variants/3-vesy-*` | «В долгосрочной перспективе рынок — весы»: цена на одной чаше, заработок на другой. |
| `logo-variants/4-shchit-*` | Запас прочности как защита; внутри тот же график. |
| `logo-variants/5-kniga-*` | «Разумный инвестор», открытый на графике. |
| `logo-variants/6-cena-i-stoimost-*` | Две полосы — стоимость и цена, зелёный разрыв — запас; читается как «≥». |

`*-dark.svg` — основной знак на тёмном фоне, `*-light-favicon.svg` — упрощённый
вариант для светлой темы в размере 32 px (у весов и щита мелкие детали убраны).

Кандидаты — 1 и 6: оба рассказывают именно метод проекта и читаются в 32 px.
