# Graham Analyzer

Оценка российских акций по методу Бенджамина Грэма и Дэвида Додда — из отчётов
МСФО за много лет, без прогнозов аналитиков и без рекомендаций.

**Сайт:** https://graham-analyzer.ru · **Telegram:** [@graham_analyzer](https://t.me/graham_analyzer)

Что здесь есть:

- **Карточка компании** — отчётность МСФО за годы, нормализованная прибыль, опорная
  стоимость и запас прочности, график цены против оценки на каждую дату, дивиденды,
  мультипликаторы и происхождение каждого числа.
- **Скринер** — требования Грэма к защитному и активному инвестору с отраслевыми
  порогами для российского рынка.
- **Рынок** — P/E рынка за годы и доходность прибыли против десятилетних ОФЗ.
- **Экономика** — бюджет, госдолг, ФНБ, инфляция, кредит, курсы и снимок на любую
  дату: что тогда было с рынком и какие компании стоили дешевле своей оценки.

Стек: FastAPI, PostgreSQL, React, Docker Compose, Caddy.
